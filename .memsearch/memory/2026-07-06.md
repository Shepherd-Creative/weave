- User asked: codex, please describe this project
- Codex: Weave is a TypeScript monorepo for building dashboards that an LLM can compose as validated JSON.

The core flow is:

```text
LLM + composition skill
        ↓
JSON dashboard specification
        ↓
Zod validation / MCP render tools
        ↓
React <Weave> renderer
        ↓
Host application’s theme
```

The host application controls the visual design through CSS variables; the LLM only chooses the content and composition.

Core packages:

- `weave-primitives`: 13 React components covering metrics, charts, tables, notes, grids, and stacks. It includes the Zod schemas and recursive renderer.
- `weave-mcp-server`: exposes five dashboard tools through REST and MCP Streamable HTTP.
- `weave-skill`: teaches an LLM how and when to compose the available primitives.
